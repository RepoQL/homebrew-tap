# RepoQL Homebrew Tap

Homebrew formulae for [RepoQL](https://repoql.ai) — extra senses for coding agents.

## Install

```sh
brew install repoql/tap/rql
```

Then run `rql install` to set up agent integrations.

## Update

```sh
brew upgrade rql
```

## About this tap

Formulae here are rendered artifacts, published automatically by the RepoQL release pipeline on every versioned release. Do not edit them by hand — changes will be overwritten by the next release.
